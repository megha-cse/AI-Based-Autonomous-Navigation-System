# AI-Based Autonomous Navigation System

## 1. Project Overview
The AI-Based Autonomous Navigation System is a software simulation that demonstrates how a robot can find a path from a starting point to a destination while avoiding obstacles.

## 2. Objectives
- Simulate autonomous robot movement.
- Identify a path from start to goal.
- Avoid obstacles during navigation.
- Demonstrate path planning using the A* algorithm.

## 3. Technologies Used
- Python
- Pygame
- NumPy
- Matplotlib

## 4. Algorithm
The A* search algorithm is used for path planning. It calculates the cost of reaching a position and estimates the remaining distance to the goal to find a suitable path.

## 5. Working
1. A grid environment is created.
2. Obstacles are placed on the grid.
3. The starting point and destination are defined.
4. The A* algorithm calculates a path.
5. The robot follows the calculated path to reach the destination.

## 6. Controls
- R: Restart the simulation.
- Esc: Exit the simulation.

## 7. Result
The simulation demonstrates a robot navigating through a grid environment, avoiding obstacles and reaching the destination using the A* path-planning algorithm.
